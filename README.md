# 暗兽棋

基于 Vue 3、TypeScript 和 Vite 开发的本地暗兽棋小游戏。游戏采用 4 × 4 交叉点棋盘、翻牌定阵营和独立公共大本营规则，支持本地双人和人机对战。

## 功能

- 本地双人对战
- 人机对战
- 翻开第一枚棋子后确定双方阵营
- 可选“只有猫能吃鼠”规则
- 豹可八方向移动
- 同级棋子相撞后双方对死
- 鼠可吃象，象不能吃鼠
- 独立公共大本营
- 大本营内棋子受外部敌棋保护
- 大本营占用时，豹不能进入或沿中央对角线穿过大本营
- 悔棋、重开和返回菜单
- 动物图标棋子和红黑阵营视觉区分

## 技术栈

- Vue 3
- TypeScript
- Vite
- ES6 Modules
- Unicode 动物图标

## 环境要求

- Node.js 18 或更高版本
- pnpm 9 或更高版本，推荐使用 pnpm 管理依赖

## 安装依赖

```powershell
pnpm install
```

如果 pnpm 提示 `esbuild` 的构建脚本被忽略，执行：

```powershell
pnpm approve-builds
```

在列表中选中 `esbuild` 并确认，再执行一次安装或构建命令。

## 局域网联机

先启动 WebSocket 服务端：

```powershell
pnpm server
```

服务端监听 `0.0.0.0:3000`。再启动前端开发服务并让局域网设备访问本机 IP：

```powershell
pnpm dev -- --host 0.0.0.0
```

在页面选择“局域网联机”，一端创建房间，另一端输入 6 位房间号加入。两台设备需要位于同一局域网，并允许防火墙访问 3000 端口。

## 本地开发

```powershell
pnpm dev
```

Vite 启动后，在浏览器中打开终端显示的本地地址，通常为：

```text
http://localhost:5173/
```

## 核心规则

### 棋盘与阵营

棋盘由 4 × 4 个交叉点组成，共有 16 枚棋子。红黑双方各有象、狮、虎、豹、狼、狗、猫、鼠各一枚。

开局所有棋子背面朝上。首位翻开棋子的玩家获得该棋子的阵营，对手自动获得另一阵营。

### 移动与吃子

普通棋子可以上下左右移动一格，豹还可以沿斜方向移动一格。等级由高到低为：

```text
象 > 狮 > 虎 > 豹 > 狼 > 狗 > 猫 > 鼠
```

高等级棋子可吃低等级棋子；相同等级相撞时双方同时移除。

鼠能吃象，但象永远不能吃鼠。可在开始对局前选择是否限制为只有猫能吃鼠。

### 公共大本营

中央方格内部是独立的大本营位置，四个中央交叉点均可作为入口。

- 大本营内最多容纳一枚棋子
- 外部敌棋不能攻击营内棋子
- 营内棋子可移动或攻击四个入口上的敌棋
- 大本营有棋子时，豹不能进入大本营
- 大本营有棋子时，豹不能沿两条穿过中央营位的对角线飞行

## 后续联机扩展建议

核心规则位于 `src/game/rules.ts`，不依赖 Vue、DOM 或浏览器 API。未来开发联机模式时，可将该规则模块迁移或复用到 Node.js 服务端。

推荐的联机架构：

```text
Vue 客户端
  ↓ 发送操作意图
WebSocket 服务端
  ↓ 验证操作与更新对局
规则引擎
  ↓ 广播最新棋局
所有客户端
```

客户端只提交翻牌、移动、投降等操作意图；服务端必须使用规则引擎校验合法性并作为唯一的对局状态来源。
